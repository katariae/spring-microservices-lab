- [ ] **0–10 · Recall:** answer yesterday's 3 questions from memory, then check
- [ ] **10–60 · Course:** watch and type along. Pause before the instructor types and predict what comes next
- [ ] **60–75 · Make it mine:** change one thing, break something on purpose, or write a pytest test
- [ ] **75–90 · Log + commit:** write today's entry below, commit, push
